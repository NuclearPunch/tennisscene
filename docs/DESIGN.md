# 시각 언어

`designer` 에이전트가 소유한다. 토큰은 `src/app/globals.css`, 로고는 `src/components/Logo.tsx`.

## 기준 — 쓰레드 앱

**기준은 쓰레드 iOS 앱이다.** 2026-09-21 에 사용자가 앱 화면을 직접 보여주며 확정했다.
"쓰레드를 참고한 다른 무엇"이 아니라 **그 문법 그대로** 간다:

| 쓰레드 앱 | 테니스씬 |
|---|---|
| 시스템 서체 (SF Pro + Apple SD Gothic Neo) | 같다. 애플 밖에서는 같은 골격의 Pretendard 로 받는다 |
| 흑백. 시스템 라이트/다크를 따른다 | 같다. `prefers-color-scheme` 으로 토큰이 통째로 바뀐다 |
| 단색 선 심벌 + 굵고 기운 워드마크, 가운데 | 같다. 공 테두리와 솔기를 한 굵기의 선으로 |
| 떠 있는 유리 알약 탭바, 활성 탭에 밝은 알약 | 같다 (`glass`) |
| 맨 위 "새로운 소식이 있나요?" | `ComposePrompt` — "오늘 코트에서 무슨 일이 있었나요?" |
| 아바타 40pt, 넉넉한 줄간격 | 40px, 15/24 |
| 0.5px 구분선, 12px 카드, 0 은 안 씀 | 같다 |

우리 것은 두 가지뿐이다 — **딥그린 아바타**(자동 게시 계정)와 **테니스공색 표식**(`1위` `우승`).

### 철회한 방향 — 되살리지 말 것

같은 날 먼저 시도했다가 버렸다. **"부드럽고 감각적"을 세리프와 크림색으로 해석한 것**이 틀렸다.

- 종이색 바탕(`#F6F4EE`) + 흰 카드 → 잡지처럼 보인다. 쓰레드는 순수 흑/백이다
- 이름·제목에 마루 부리(세리프) → SNS 가 아니라 신문이 된다
- 본문 SUIT → 시스템 서체가 아니면 "앱"처럼 안 보인다
- 컬러 심벌(딥그린 공 + 옐로우 솔기) → 쓰레드의 로고는 색이 없다
- 바닥에 붙은 탭바 → 떠 있어야 한다

### 로고

**심벌** — 공의 테두리와 솔기를 **같은 굵기(13)의 선 하나**로 그린다(100 상자, r43.5).
굵기는 한나체의 세로획에 맞췄다 — 심벌과 글자가 같은 펜으로 그린 것처럼 보여야 한다.
솔기는 반지름 32 의 반원 둘을 중심에서 이은 S 이고 −35° 로 기울어 워드마크의 기울기와 맞는다.
공 밖까지 그린 뒤 테두리 안쪽으로 잘라 끝이 깔끔하게 붙는다. 원호 두 개라 16px 에서도 안 흔들린다.

**워드마크** — **배달의민족 한나체 Pro** 로 짠 `테니스씬` 을 글꼴 파일에서 **윤곽선으로 뽑아**
−10° 기울이고 자간을 −0.02em 조였다. 글꼴이 아니라 도형이라 웹폰트를 싣지 않는다.

서체는 **사용자가 직접 골랐다**(2026-09-21). 기업 공개 서체 20종을 실제 심벌 옆에 놓은
비교판(`public/fonts.html`)에서 A19 를 택했다. 본문은 B1 — 시스템 서체 그대로다.
한나체는 SIL OFL 1.1 이고(글꼴 파일의 라이선스 항목에서 확인), OFL 은 글꼴로 만든 결과물에
조건을 걸지 않아 로고에 쓸 수 있다.

**색이 없다.** `currentColor` 라 라이트에서 검정, 다크에서 흰색이 된다.
파일: `src/components/Logo.tsx`(생성물) · `public/logo.svg` · `src/app/icon.svg` · `src/app/apple-icon.tsx`

## 이전 디자인이 AI 가 만든 것처럼 보였던 이유

취향 문제가 아니라 짚을 수 있는 실수였다. 되돌아가지 않게 적어둔다.

| 실수 | 왜 티가 나나 | 지금 |
|---|---|---|
| 회색마다 그린을 섞었다 (`#FBFCFB` `#0E1A14` `#5A6B62`) | "브랜드 컬러가 은은하게 밴 중성색"은 생성된 팔레트의 전형이다 | 무채색은 진짜 무채색. `#FFF` `#000` `#737373` |
| 글자 크기가 10.5·11.5·12.5·13.5·14.5·15·17·32 | 요소마다 "적당히" 고른 값. 체계가 없다는 증거다 | **13 · 15 · 20** 셋뿐 |
| 거의 모든 글자에 음수 자간 | 손댄 티를 내려는 장식 | 20px 한 곳에만 `-0.01em` |
| 옅은 그린 원 + 선 아이콘 아바타 | 설정 화면 메뉴 아이콘 모양이다. 계정처럼 안 보인다 | 꽉 찬 딥그린 원 + 채운 아이콘. 공식 계정의 로고 사진처럼 |
| 랭킹마다 딥그린 블록 + 반투명 공 장식 | 한 장이면 주인공인데 피드에 20장이 쌓이면 소음이다 | 흰 카드 + 테니스공색 표식 하나 |
| 대문자풍 10.5px 자간 넓힌 머리글 | 대시보드 템플릿의 단골 | 13px 회색 한 줄 |
| 포스트 하나에 상자 둘 (1위 블록 + 펼침 버튼 상자) | 구조가 아니라 장식으로 나눈 것 | 카드 하나, 그 안에서 펴진다 |
| 부서를 회색 칩으로 나열 | 눌리지도 않는 칩은 그냥 잡음 | `개나리부 · 국화부` 한 줄 |
| 새 글마다 `0 0 0` | 조용한 서비스라고 광고하는 셈 | 0 은 안 쓴다 |
| 활동 탭에 항상 켜진 알림 점 | 가짜 상태. 한 번 눌러보면 들통난다 | 뺐다. 실제 알림이 생기면 붙인다 |
| `이름 @핸들 · 시간` | 한 줄에 정보 셋. 눈이 시간을 못 찾는다 | `이름 ✓ 시간` |

## 실측 — 쓰레드 모바일 웹 (라이트)

```
글자        15px / 21px, 자간 없음, 시스템 서체. 이름 600 · 본문 400 · 시간 400
            반응 숫자만 13px. 프로필 제목 24/700
색          바탕 #FFF · 글자 #000 · 시간·메타 #999 · 반응 아이콘 #424242
구분선      0.5px rgba(0,0,0,0.15)
포스트      패딩 12px. 격자 48px | 1fr — 아바타 36px + 간격 12px
반응 줄     터치 36px, 아이콘 20px, 첫 아이콘이 본문 왼쪽 선에 맞게 줄을 당김. 0 은 안 씀
미디어      모서리 8px
버튼        높이 34px, 모서리 10px, 테두리 1px rgba(0,0,0,0.15), 주 버튼은 검정
탭바        아이콘 26px, 비활성 #B8B8B8, 가운데 작성만 회색 둥근 사각형
```

그대로 가져온 것과 바꾼 것:

- **줄높이 22px** (쓰레드 21). 한글은 받침 때문에 1px 더 필요하다
- **메타 `#737373`** (쓰레드 `#999`). `#999` 는 흰 바탕 위 2.8:1 로 본문 대비 하한(4.5:1)을 못 넘는다
- **옆 여백 16px** (쓰레드 12). 한글은 글자가 꽉 차서 가장자리가 더 답답하다

## 타이포 — 시스템 서체, 크기 셋

```
-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Pretendard Variable", system-ui
```

| 크기 | 줄높이 | 쓰는 곳 |
|---|---|---|
| 15 | 24 | **기본값.** 이름·본문·시간·반응 숫자·버튼. `body` 에 걸려 있어 클래스가 필요 없다 |
| 13 | 18 | 메타, 소속, 카드 아래 링크 줄 |
| 20 | 26 | 카드의 주인공 한 줄 — 1위 이름, 우승 조. 여기만 `-0.01em` |

12px 는 테니스공색 표식 안 글자와 `NEW` 두 곳뿐이다. **그 사이 값은 만들지 않는다.**
줄높이 24 는 쓰레드 앱 화면에서 잰 한글 줄간격 비율(1.6)이다 — 모바일 웹(1.4)보다 넉넉하다.

위계는 굵기(400 / 600 / 700)와 색(`ink` / `ink-3`)으로 만든다.
`tabular-nums` 는 `.num` 에만 건다. `word-break: keep-all` — 한글은 어절 단위로 끊는다.

## 색

토큰은 `:root` 의 CSS 변수이고 `prefers-color-scheme: dark` 에서 통째로 바뀐다.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `bg` `surface` | `#FFFFFF` | `#101010` | 지면과 카드. 카드는 테두리로만 선다 |
| `grouped` | `#F5F5F5` | `#1E1E1E` | 이미지 자리, 기본 아바타 |
| `hairline` | `rgba(0,0,0,.15)` | `rgba(243,245,247,.15)` | 0.5px 선 |
| `ink` | `#000000` | `#F3F5F7` | 본문, 로고, 탭 아이콘 |
| `ink-2` | `#424242` | `#CCCCCC` | 반응 아이콘 |
| `ink-3` | `#737373` 4.7:1 | `#8A8A8A` 5.5:1 | 시간·메타·반응 숫자 |
| `green` | `#0F7A4F` 5.4:1 | `#35C48B` 8.6:1 | 배지, 좋아요, `NEW` |
| `down` | `#D64545` | `#FF6B5E` | 순위 하락 |
| `green-deep` | `#0B4A33` | 같음 | 자동 게시 계정 아바타, 표식 글자 |
| `ball` | `#D8F550` | 같음 | 표식 채움, 아바타 아이콘 |

**색은 뜻이 있을 때만 쓴다.** 화면은 흑백이고, 색이 보이면 그건 정보다.

### 테니스공색 표식 — 이 앱의 서명

`1위` `우승` 을 테니스공색 조각에 딥그린 글자로 찍는다(9.6:1). 라이트·다크에서 같은 색이다.
옐로우를 밝은 바탕 위 **글자로** 쓰지 않는다(1.1:1).

## 형태

- 모서리: **카드 12px, 미디어 8px**, 칩·버튼·탭바는 알약. 그림자는 떠 있는 탭바 하나뿐이다
- 첨부는 전부 같은 그릇 — 지면과 같은 바탕, 0.5px 테두리, 12px. **첨부가 본문보다 시끄러우면 안 된다**
- 카드 안 구획은 `hair-t` 한 줄로만 나눈다. 배경색 띠를 깔지 않는다
- 헤더에는 로고(심벌 + 워드마크)를 가운데에 건다
- 탭바는 떠 있다. `main` 에 `pb-28` 을 줘서 마지막 글이 가려지지 않게 한다
- 터치 타깃: 반응 40px, 탭 52px, 카드 링크 줄 44px

## 아이콘 — `@phosphor-icons/react`

UI 아이콘은 직접 그리지 않는다. 획 굵기·광학 크기가 미세하게 어긋나면 아마추어처럼 보인다.
`regular` → `fill` 로 활성을 표현한다. 아바타 안 아이콘은 `fill` — 선 아이콘은 18px 에서 뭉개진다.

**직접 그리는 건 배지(`Verified`) 하나다.** 로고는 `Logo.tsx` 에 따로 있다.
배지는 꽉 채운 원에 흰 체크다. 옅은 원에 색 체크는 "인증"이 아니라 "장식"으로 읽힌다.
